# `stat-plugin-kaplan-meier_core`

Kaplan-Meier statistic access-rule core package.

Concepts:
- Holds the Kaplan-Meier ShEx source and generated LDO files.
- Exposes `kaplanMeierStatisticPlugin`, `KaplanMeierStatisticAccessRule`, and `KaplanMeierAllowedPath`.

Example:
```ts
import {
  kaplanMeierStatisticPlugin,
  KaplanMeierStatisticAccessRuleShapeType,
} from "@oxfordia/stat-plugin-kaplan-meier_core";
```
