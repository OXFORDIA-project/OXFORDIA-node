# `stat-plugin-kaplan-meier_ui`

Kaplan-Meier statistic access-rule UI plugin.

Concepts:
- Packages the Kaplan-Meier policy editor for the shared statistic-access-rule view.
- Supplies `createPolicy`, `isPolicy`, and the editor component as `kaplanMeierStatisticPluginUi`.

Example:
```ts
import { kaplanMeierStatisticPluginUi } from "@oxfordia/stat-plugin-kaplan-meier_ui";
```
