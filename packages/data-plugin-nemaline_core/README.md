# `data-plugin-nemaline_core`

Nemaline data-plugin core package.

Concepts:
- Holds the nemaline ShEx source and generated LDO files.
- Exposes typed shape objects like `PersonShapeType`.
- Publishes the nemaline graph-path shortcut catalog through `nemalineDataPlugin`.

Example:
```ts
import { nemalineDataPlugin, PersonShapeType } from "@oxfordia/data-plugin-nemaline_core";
```
