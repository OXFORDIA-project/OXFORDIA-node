# `stat-plugin-count_ui`

Count statistic access-rule UI plugin.

Concepts:
- Packages the count policy editor for the shared statistic-access-rule view.
- Supplies `createPolicy`, `isPolicy`, and the editor component as `countStatisticPluginUi`.

Example:
```ts
import { countStatisticPluginUi } from "@oxfordia/stat-plugin-count_ui";
```
