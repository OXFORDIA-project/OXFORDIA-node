# `stat-plugin_ui`

UI-side statistic-plugin contract and shared editor utilities.

Concepts:
- Defines `StatisticPluginUi` for statistic access rule editors.
- Holds shared graph-path editor helpers and schema option resolution.

Example:
```ts
import type { StatisticPluginUi } from "@oxfordia/stat-plugin_ui";
import { GraphPathFieldEditor } from "@oxfordia/stat-plugin_ui";
```
