# `stat-plugin-mean_ui`

Mean statistic access-rule UI plugin.

Concepts:
- Packages the mean policy editor for the shared statistic-access-rule view.
- Supplies `createPolicy`, `isPolicy`, and the editor component as `meanStatisticPluginUi`.

Example:
```ts
import { meanStatisticPluginUi } from "@oxfordia/stat-plugin-mean_ui";
```
