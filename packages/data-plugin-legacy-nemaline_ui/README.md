# `data-plugin-legacy-nemaline_ui`

Legacy nemaline linked-data-browser UI package.

Concepts:
- Packages the legacy nemaline `ResourceView` and `ResourceCreator`.
- Keeps the old nemaline table view and CSV importer in plugin form.

Example:
```ts
import { legacyNemalineDataPluginUi } from "@oxfordia/data-plugin-legacy-nemaline_ui";
```
