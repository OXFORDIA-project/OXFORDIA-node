# `data-plugin-nemaline_ui`

Nemaline linked-data-browser UI package.

Concepts:
- Packages the nemaline `ResourceView` and `ResourceCreator`.
- Keeps the old nemaline table view and CSV importer in plugin form.

Example:
```ts
import { nemalineDataPluginUi } from "@oxfordia/data-plugin-nemaline_ui";
```
