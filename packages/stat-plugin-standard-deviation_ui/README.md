# `stat-plugin-standard-deviation_ui`

Standard deviation statistic access-rule UI plugin.

Concepts:
- Packages the standard deviation policy editor for the shared statistic-access-rule view.
- Supplies `createPolicy`, `isPolicy`, and the editor component as `standardDeviationStatisticPluginUi`.

Example:
```ts
import { standardDeviationStatisticPluginUi } from "@oxfordia/stat-plugin-standard-deviation_ui";
```
