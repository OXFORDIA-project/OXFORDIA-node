# `stat-plugin-mean_core`

Mean statistic access-rule core package.

Concepts:
- Holds the mean-specific ShEx source and generated LDO files.
- Exposes `meanStatisticPlugin`, `MeanStatisticAccessRule`, and `MeanAllowedPath`.

Example:
```ts
import { meanStatisticPlugin, MeanStatisticAccessRuleShapeType } from "@oxfordia/stat-plugin-mean_core";
```
